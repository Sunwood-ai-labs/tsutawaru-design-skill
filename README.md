# 伝わるデザインスキル

[伝わるデザイン](https://tsutawarudesign.com/)を参考に、スライド・文書・ポスター・図表を読みやすく、見やすく整えるCodexスキルです。

スキル本体は [SKILL.md](SKILL.md) の1ファイルだけ。詳細なルールや実例は、必要に応じて参照サイトの該当ページを読みます。

## 導入

`~/.codex/skills/tsutawaru-design/` を作成し、このリポジトリの `SKILL.md` を配置してください。

## 使い方

対象の資料を添えて、次のように依頼します。

```text
$tsutawaru-design この資料を読みやすく、見やすく整えて
```

文字・レイアウト・図表・配色・見え方の多様性への配慮を、資料の目的に合わせて確認します。

## 参照元

[伝わるデザイン — 研究発表のユニバーサルデザイン](https://tsutawarudesign.com/)

本スキルは参照サイトの非公式スキルです。
